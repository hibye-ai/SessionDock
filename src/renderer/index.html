Telnet은 암호화되지 않으며 로그인은 연결 후 터미널에서 입력합니다.

글꼴과 간격

설치된 글꼴을 불러옵니다. 고정폭 글꼴을 권장합니다.

글꼴을 비우거나 크기·줄 간격 0, 글자 간격 -1이면 전체 설정을 따릅니다. 직접 지정: 크기 10–48px, 줄 간격 1–2배, 글자 간격 0–5px. 저장 즉시 적용됩니다.

0이면 전체 설정을 따릅니다(직접 지정: 1,000–100,000줄).

로그 저장

현재 및 새 연결을 자동 기록하며 탭 우클릭으로 개별 중지합니다.

{session} 세션 · {host} 호스트 · {username} 사용자 · {protocol} 프로토콜 · {port} 포트
{date} 날짜 · {time} 시각 · {year}/{month}/{day} 연/월/일 · {hour}/{minute}/{second} 시/분/초 · {id} 연결 번호
중복 파일은 번호를 붙여 보존합니다.

원본은 받은 데이터를 그대로 저장합니다. 일반 텍스트는 색상·제어 코드를 제외하며 시각은 한국 시간 기준입니다.
